# 🌐 Personal Portfolio – Brian Okelo

Welcome to my personal developer portfolio! This is a simple, responsive HTML & CSS project built to showcase my skills, background, and interests in tech.

## 📌 Overview

This portfolio website is structured to introduce who I am, highlight my skills and programming background, and share projects I’ve worked on. It also includes links to my CV and GitHub profile.

## 🚀 Sections Included

- **About Me**  
  A brief introduction outlining my passion for technology, software development, and what drives me.

- **Programming Languages**  
  A list of programming languages I'm currently learning or proficient in.

- **Education**  
  My academic background with potential to include downloadable CV or transcript.

- **Interests**  
  A short summary of my interests and what excites me about working in tech.

- **Projects**  
  Links to any current or future projects, with brief descriptions to give context.

- **Contact / GitHub**  
  A button or link redirecting to my GitHub profile where people can connect with my work.

## 💻 Technologies Used

- HTML5  
- CSS3  
- Git & GitHub (for version control and hosting)
